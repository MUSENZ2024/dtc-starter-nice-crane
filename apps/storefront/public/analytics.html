Connecting live data

No secret ever reaches this page. It calls a same-origin proxy at /api/analytics — a Next.js route inside the storefront app — sending the same password used at the gate above as x-gate-token. That route independently re-checks the password against MUSE_ANALYTICS_GATE_PASSWORD before using the real Medusa secret key (MUSE_ANALYTICS_MEDUSA_KEY) to call /admin/muse-analytics — both env vars are server-side only, never shipped to the browser. This means live data only works when the page is served by that storefront app (e.g. musenz.com/analytics.html); a bare static file server has no proxy to call and will fall back to demo data.

GA4: sessions, traffic sources, devices and search data come from the backend's own GA4 service-account credentials — nothing Google-related is sent to or stored in this page either.
